# Karta projektu SKW

**Nazwa:** System obsługi konsultacji wykładowców

**Akronim:** SKW

## Opis projektu

System umożliwia studentom przeglądanie dostępnych terminów konsultacji, zapisywanie się na konsultacje i anulowanie zapisów. Wykładowcy mogą zarządzać terminami oraz listami zapisanych studentów.
