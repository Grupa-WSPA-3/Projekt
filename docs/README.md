# SKW — System obsługi konsultacji wykładowców

SKW to system wspierający organizację konsultacji wykładowców na uczelni. Student może przeglądać dostępne terminy i zapisywać się na wybrany termin, a wykładowca zarządza własnymi konsultacjami oraz listą zapisanych osób. System ma ograniczać ręczną wymianę wiadomości i zapobiegać przekroczeniu limitu miejsc.
