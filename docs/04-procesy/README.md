## Konwencje
- AS-IS opisuje stan obecny; TO-BE — proces docelowy.
- Każdy krok ma identyfikator P-xx.n i odniesienie do FR/BR.
- Tory odpowiadają rolom; różne wyniki procesu mają oddzielne zdarzenia końcowe.
- Diagramy BPMN są przechowywane jako źródło .bpmn i eksport .svg.
- Nierozstrzygnięte reguły pozostają otwartymi pytaniami.

## Ograniczenie źródłowe
W przekazanych materiałach nie ma wypełnionego protokołu rzeczywistego wywiadu. P-00 oraz niepotwierdzone założenia wymagają walidacji; nie są przedstawiane jako fakty potwierdzone przez klienta.
