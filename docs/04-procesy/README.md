# Rozpoznanie procesów

Katalog przechowuje wstępne materiały do opisania sposobu organizacji konsultacji.

## Aktualny materiał

- [P-00 — notatki AS-IS](P-00-as-is-notatki.md) — hipotezy i obserwacje zespołu wymagające weryfikacji.

## Zasady

- Oddzielać stan obecny (AS-IS) od proponowanego rozwiązania (TO-BE).
- Nie przedstawiać rekonstrukcji zespołu jako potwierdzonego przebiegu procesu.
- Każdy ustalony krok, rola, reguła i wyjątek powinny mieć źródło lub oznaczenie „do potwierdzenia”.
- Formalne opisy procesów i diagramy dodawać dopiero po weryfikacji materiału źródłowego.
